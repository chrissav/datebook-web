# datebook-web

The public face of Datebook — an app for two people to plan dates together and keep the
ones they went on.

Served by GitHub Pages from `main`:

| Page | URL |
|---|---|
| Home | https://chrissav.github.io/datebook-web/ |
| Privacy policy | https://chrissav.github.io/datebook-web/privacy.html |
| Support | https://chrissav.github.io/datebook-web/support.html |

`404.html` also catches `/join/<token>` and hands the token to the app, because GitHub
Pages has no routing of its own and serves it for any unrecognised path.
